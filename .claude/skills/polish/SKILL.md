Проведи проверку качества приложения Спарки.

1. Отправь 5 субагентов (модель Sonnet) — по одному на группу ниже, **заходами не больше чем по два одновременно** (встроенный браузер общий, а лимит подписки не бесконечный): группы 1+2, потом 3+4, потом 5. Каждый работает в своей вкладке браузера. Субагенты **только ищут проблемы и ничего не меняют**. Каждый открывает приложение во встроенном браузере на 393×852, в светлой и тёмной теме, и возвращает список: где проблема, что не так, скриншот.
2. Собери все списки в один, убери дубли. Покажи владельцу простыми словами, отсортировав по важности. **Ничего не меняй, пока владелец не подтвердит.**
3. После подтверждения исправь всё сам, по одному файлу за раз (чтобы правки не пересекались). Если в списке много сложных правок, перед началом попроси владельца поднять усилие на high (Ctrl+Shift+E).
4. Прогони `npm run typecheck`, `npm test`, `npm run build`. Дай скриншоты «до» и «после» по каждой важной правке.

## Группы

**1. Единый дизайн**
- Каждый цвет, размер шрифта, отступ и скругление взяты из DESIGN.md. Нет «самодельных» значений.
- Кнопки, карточки, поля одного типа выглядят одинаково на всех экранах.
- Иерархия текста ясна: что главное на экране, видно сразу.
- Слишком плоско — добавить акцент; слишком тесно — разредить.
- Текст читается и на светлой, и на тёмной теме (контраст).

**2. Телефон**
- Нет горизонтальной прокрутки и ничего не вылезает за край экрана.
- Ничего не уходит под Dynamic Island и полоску «домой».
- Все кнопки ≥ 44 pt, по ним легко попасть большим пальцем.
- Клавиатура не закрывает поле ввода в задании «Ввод».
- Макет не ломается при крупном шрифте в настройках iPhone.

**3. Все состояния**
- У загрузки, пустых списков и ошибок есть нормальные экраны (с маскотом, где уместно).
- У каждой кнопки есть вид при нажатии и в неактивном состоянии, плюс звук и вибрация.
- Ошибки в формах показываются прямо у поля, есть сообщения об успехе и неудаче.
- Всплывашки, переходы между вкладками и экранами анимированы и учитывают «Уменьшение движения».

**4. Как настоящий пользователь**
- Пройти от начала до конца: первый запуск → добавить первые слова → урок → итог → стрик → добавить ещё слова списком → бэкап → восстановление.
- Найти кнопки, которые ничего не делают, и тупиковые экраны.
- Закрыть приложение посреди урока, открыть снова — ничего не потеряно.
- Офлайн (выключенная сеть) — всё работает.

**5. Мелочи и надёжность**
- Нет текстов-заглушек, опечаток, английских кусков в русском интерфейсе.
- У приложения правильные название, иконка и цвет статус-бара.
- В консоли браузера нет ошибок и предупреждений.
- Первая загрузка < 300 КБ (gzip), анимации плавные.
