Образцы файлов бэкапа старых версий. **Не править и не удалять** — тест в `../backup.test.ts`
проверяет, что каждый из них восстанавливается в текущей версии приложения (CLAUDE.md → «Данные — святое»).
Когда меняется формат (`BACKUP_FORMAT` в `../schema.ts`) — добавить сюда новый образец `backup-vN.json`.

- `backup-v1.json` — настоящий файл формата 1, снятый с тестовой базы (этап 5).
- `backup-v1-minimal.json` — формат 1 с минимумом полей: проверяет, что недостающее заполняется по умолчанию.
